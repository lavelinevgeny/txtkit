# Favicon — сетка квадратов

**Дата:** 2026-05-27
**Статус:** утверждён

## Решение

Новый favicon для txtkit — SVG иконка в виде сетки 2x2 из квадратов с разной непрозрачностью акцентного цвета `#e8a030` на тёмном фоне `#18181b`.

## Визуальное описание

- Квадратный canvas с закруглёнными углами (rx=24)
- Тёмный фон `#18181b`
- 4 квадрата в сетке 2x2, каждый 36x36, скругление rx=8
- Непрозрачность: верхний-левый 0.9, верхний-правый и нижний-левый 0.6, нижний-правый 0.3
- Цвет заливки: `#e8a030` (акцентный цвет проекта)
- Размер viewBox: 120x120

## Семантика

Сетка блоков с градиентом прозрачности передаёт идею «набора инструментов» — разные утилиты разной «плотности» в одном комплекте.

## Технические требования

- Формат: SVG (`public/favicon.svg`)
- Заменяет существующий favicon (молния)
- `index.html` уже ссылается на `/favicon.svg` — менять не нужно
