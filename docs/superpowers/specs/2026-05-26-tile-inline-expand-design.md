# Inline Expand для ResultTile — Design Spec

## Проблема

Текущий механизм копирования с плиток имеет три недостатка:
1. Пользователь не ожидает, что клик затирает буфер обмена
2. Длинные значения обрезаются (`truncate`) — невозможно увидеть полностью
3. Tooltip с полным значением выглядит устаревшим

## Решение

При клике плитка раскрывается на месте (inline expand), показывая полное значение и кнопку «Скопировать». Буфер обмена не затрагивается без явного нажатия кнопки.

## Поведение

### Раскрытие
- Клик по обычной плитке → плитка раскрывается на месте
- Раскрытая плитка занимает всю ширину сетки (`col-span-2`)
- Показывает: ярлык (label), полное значение (с прокруткой если длинное), кнопку «Скопировать»
- Только одна раскрытая плитка в любой момент времени

### Закрытие
- Повторный клик по раскрытой плитке → сворачивает
- Клик по другой плитке → сворачивает текущую, раскрывает новую
- Изменение входного текста → сворачивает все плитки (сброс состояния)

### Копирование
- Кнопка «Скопировать» — вызвает `copyToClipboard(value)`
- После успешного копирования кнопка меняется на «✓ Скопировано» на 1.5с
- После 1.5с кнопка возвращается в исходное состояние

## Визуальные изменения

### Обычная плитка (без изменений)
- `border: border-border (#27272a)`
- Значение: `truncate` (обрезается с многоточием)

### Раскрытая плитка
- `border: border-accent (#e8a030)` — amber рамка
- Значение: `word-break: break-all`, `max-height` с `overflow-y: auto` для прокрутки
- Кнопка «Скопировать» — amber фон, dark текст
- Плавный transition на `max-height` и `border-color`

## Убирается

- Toast уведомление «Скопировано!» (компонент Toast и showToast) — больше не нужен
- Атрибут `title` на плитке с подсказкой — раскрытая плитка заменяет

## Не меняется

- Сетка `grid-cols-2`
- Лимит отображения (8 плиток + «Показать все»)
- Логика фильтрации по `activeToolId`
- Компонент ResultTiles (контейнер)
- Утилита `copyToClipboard`

## Затронутые файлы

- `src/components/ResultTile.tsx` — основная переработка (состояние раскрытия, рендер expanded view, кнопка копирования с чекмарком)
- `src/components/ResultTiles.tsx` — передача `expandedId` + `onToggleExpand` в дочерние плитки; `col-span-2` для раскрытой
- `src/components/Toast.tsx` — удалить
- `src/store/useStore.ts` — убрать `showToast` (если не используется в других местах)
- `src/App.tsx` — убрать `<Toast />` из рендера

## Граничные случаи

- Пустое значение в плитке — не показывать кнопку «Скопировать»
- Очень длинные значения (Base64 и т.д.) — `max-height` + `overflow-y: auto` с кастомным скроллбаром
- Быстрые повторные клики — debounce не нужен, toggle работает атомарно
- Мобильные устройства — раскрытая плитка адаптируется к `grid-cols-1`
