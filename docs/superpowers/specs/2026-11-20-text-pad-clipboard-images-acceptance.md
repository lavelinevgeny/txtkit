# Проверка изображений Text Pad в браузерах, 20 ноября 2026

Среда — Ubuntu 24.04.4, ARM64, отдельный дисплей X11 (Xvfb). Playwright управлял настольными окнами Chromium 153.0.8010.12 и Firefox 157.0. Системный буфер проверялся через Ctrl+V. Типы считаны непосредственно из `paste.clipboardData`, у этих событий `isTrusted === true`.

| Источник в Ubuntu | Chromium | Firefox | Что появилось в Pad |
| --- | --- | --- | --- |
| Снимок экрана 1100 × 600, получен из окна X11 и помещён в системный буфер через GTK 3 | `Files` с `image/png` | `Files` с `image/png` | Одна миниатюра между абзацами «до» и «после». Следующий введённый символ оказался сразу после неё. |
| Контекстное меню браузера «Copy Image» для PNG на странице | `text/html`, `Files` с `image/png` | `text/html`, `Files` с `image/png` | Одна миниатюра. В обоих событиях plain-текст был пуст. |
| Ctrl+C в другом окне браузера, выделена строка HTML-таблицы | `text/plain`, `text/html` | `text/html`, `text/plain` | Текст двух ячеек с табуляцией между ними. |
| Ctrl+C в другом окне браузера, выделен абзац с полужирным словом | `text/plain`, `text/html` | `text/html`, `text/plain` | Строка `Hello world`. |

В Chromium и Firefox после автосохранения, перезагрузки и переключения вкладок заметки в режиме Playwright offline миниатюра сохранила исходные размеры 1100 × 600. При переносе выделения мышью во внешнее поле страницы получатель увидел `before[image] after` и режим `copy`. При переносе внутри редактора текст и привязка сохранились.

## Проверки с заданными данными события

Для смешанного буфера тест создавал `DataTransfer` с пробелом в `text/plain`, HTML и файлом PNG. Вставился один пробел. HTML без текста, отдельно PDF и отдельно TIFF оставили выделенный пробел на месте. Для этих проверок, а также для файлов контролируемого размера событие `paste` создавалось программно.

- PNG 2000 × 120 при сужении окна с 1080 до 640 CSS-пикселей уменьшился с 961 до 545 пикселей с округлением. Обе ширины укладывались в доступную область после вычета гуттера и отступов. Перенос строк и спецсимволы сохраняли миниатюру. PNG 220 × 2000 занял 480 пикселей по высоте при обоих режимах переноса строк.
- При вставке трёх недекодируемых байтов с MIME `image/png` на месте миниатюры появилось сообщение об ошибке. Закрытие и восстановление вкладки сохранило это состояние. Один Undo вернул прежнее изображение.
- После удаления изображения и завершения записи переход на другую вкладку и обратно сохранил возможность Undo. В скачанном общем JSON сверены MIME и все байты обоих изображений с записями IndexedDB.

## Доступность платформ

Microsoft Office, Finder и Safari отсутствовали в этой среде. Строка таблицы и форматированный фрагмент в таблице выше взяты из браузеров. В дополнительном прогоне WebKitGTK 26.6 системный Ctrl+V после копирования снимка из GTK доставил событие с пустыми `types`, `items` и `files`. При явно переданном PNG миниатюра отобразилась. После перезагрузки и переключения вкладок с заблокированными HTTP(S)-запросами она также отображалась. В режиме Playwright offline при `navigator.onLine === false` контрольный PNG из canvas загрузился по `data:`, а обращения к `blob:` и чтение локального Blob через FileReader завершились ошибкой. После добавления однократного повтора из байтов в памяти Pad показал PNG 1100 × 600 при повторной активации вкладки в этом режиме. Проверки размеров, Undo и байтов в JSON также прошли в WebKitGTK.
