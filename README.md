# txtkit

Набор текстовых инструментов, работающих прямо в браузере. Без регистрации, без сервера — всё на клиенте.

## Инструменты

Приложение само определяет тип вставленного текста (JSON, YAML, блоки 1С и др.) и поднимает подходящие инструменты наверх.

| Инструмент | Возможности |
|------------|-------------|
| **JSON** | Валидация, lint с позицией ошибки, форматирование, минификация, flatten/unflatten, JSON ↔ YAML, структура, escape/unescape, интерактивное дерево |
| **YAML** | Валидация, форматирование, YAML → JSON, структура, интерактивное дерево |
| **Списки** | Замена маркеров (`-`, `*`, `•`, нумерация, чекбоксы), удаление маркеров, сортировка, удаление дублей |
| **Регистр** | 17 форматов: camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Title Case и др. |
| **Преобразования** | Реверс, trim, капитализация, slugify, удаление дублей и сортировка строк, leet speak, морзе, двоичный код |
| **Статистика** | Символы, слова, строки, предложения, уникальные слова, байты (UTF-8), время чтения |
| **Кодирование** | Base64, URL encode/decode, HTML escape/unescape, экранирование кавычек |
| **Блоки 1С** | Валидация, форматирование, минификация, статистика, конвертация в JSON, извлечение вложенного JSON, разбиение на блоки, дерево и поля журнала регистрации |
| **Блокнот** | Редактор больших текстов с вкладками, поиском и заменой (в т. ч. regex), быстрыми операциями, автосохранением в браузере и выгрузкой в файл |
| **Mermaid** | Живой предпросмотр диаграмм (flowchart, sequence, class, state, ER, Gantt, pie и др.), масштабирование, экспорт в SVG и PNG |
| **Сравнение текстов** | Diff бок о бок с построчной и пословной подсветкой, игнорирование регистра и пробелов, статистика, мини-карта различий |

## Стек

React 19, TypeScript, Vite, Tailwind CSS 4, Zustand, CodeMirror 6, Mermaid, IndexedDB (idb), Vitest

## Разработка

```bash
npm install
npm run dev
```

`npm install` включает pre-commit хук из `.githooks/`, который проверяет коммиты на секреты через [gitleaks](https://github.com/gitleaks/gitleaks#installing). Если gitleaks не установлен, проверка пропускается; в CI она выполняется всегда.

## Тесты и линтинг

```bash
npm run test
npm run lint
```

## Сборка

```bash
npm run build
```

Результат — в папке `dist/`.

## Деплой

Приложение полностью статическое: после `npm run build` содержимое `dist/` можно разместить на любом веб-сервере или статическом хостинге.

### Релиз

Одной командой — проверки, bump версии, коммит с тегом и push:

```bash
npm run release:patch   # 1.0.0 → 1.0.1
npm run release:minor   # 1.0.0 → 1.1.0
npm run release:major   # 1.0.0 → 2.0.0
```

Каждая команда выполняет: `lint → test → build → bump версии → коммит + тег → push`.
